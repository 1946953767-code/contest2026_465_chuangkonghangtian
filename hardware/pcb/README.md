# hardware/pcb — 箭载端两块板（嘉立创 EDA 专业版工程）

本目录是箭载端两块 PCB 的**可编辑工程源文件**（EasyEDA Pro / 嘉立创 EDA 专业版 v4.1.78 导出）。

| 文件 | 板子 | 说明 |
| :-- | :-- | :-- |
| `箭载主板_ESP32S3最小系统板.epro2` | 箭载主板 | ESP32-S3-WROOM-1 最小系统：模组座、复位按键、自动下载电路、电源开关 + 自恢复保险丝、3.3 V 电源指示、WS2812 状态灯、双排母引出全部 IO |
| `传感器扩展板.epro2` | 传感器扩展板 | 叠插在主板上的扩展板：IMU / 气压 / 温湿度 / OLED / LoRa / GNSS / TF 卡的接口与分舱布置 |

## 怎么打开

1. 下载安装 **嘉立创 EDA 专业版**（EasyEDA Pro，免费）：<https://pro.lceda.cn/>
2. 打开客户端 → `文件 → 导入 → 嘉立创EDA(专业版)工程` → 选 `.epro2`
3. 工程内同时包含**原理图**与**PCB**，可直接查看网络、封装、BOM，也可以继续改板再下单

> `.epro2` 本质是一个 zip 包（`project2.json` + `.epru` + 预览图），里面没有编译产物，属于纯设计源文件。

## 与代码的对应关系

| 设计 | 固件 | 引脚 |
| :-- | :-- | :-- |
| 箭载主板 | `hardware/esp32/central_tx.py` | RGB = IO38，按键 = IO0，USB = IO19/20 |
| 传感器扩展板 | 同上 | IMU I²C = 40/39，气压+温湿度 I²C = 13/12，OLED = 48/42，GNSS = TX4/RX10，LoRa = TX14/RX21，TF = CS7/SCK5/MOSI6/MISO11，蜂鸣器 = IO17 |

## 说明

- 主板是**自研的最小系统底板**，不是市售开发板：模组直接贴板，IO 按数字顺序排列，省掉面包板和杜邦线；
- 扩展板把传感器/电台/存储做成分舱，两块板叠插成整机，这也是"六块板收敛成两张圆盘"的来源；
- 只保留设计源文件，不含 Gerber/BOM（体积大且可随时从工程导出）。
